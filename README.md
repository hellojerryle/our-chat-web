# 我们的聊天 · 网页查看器

一个静态、只读的聊天记录查看器。打开时显示明确标注的演示内容；用户自行从设备导入聊天 JSON 和对应的媒体 ZIP。

支持聊天气泡、双方头像、关键词查找、查看消息上下文、按日期定位，以及本地图片、音频、视频和附件。可添加到手机桌面；首次加载成功后可离线打开。

照片与表情按原始消息类型分别查找；转账类消息展示已保留的金额和原说明，不推断收款或退回状态，也不汇总为账单。普通文字提到“转账”不会被当作转账卡片。

## 隐私与保存

- 本仓库仅包含程序、通用图标、演示内容和合成测试。没有真实聊天、个人头像或附件。
- 导入内容保存在当前浏览器的 IndexedDB；程序没有上传、登录、分析统计或外部资源依赖。
- CSP 限制页面连接；Service Worker 只缓存固定程序文件。
- GitHub 会处理正常网站访问请求。程序本身不发送导入内容。
- 浏览器存储不是备份。清除网站数据、换网址或换浏览器后需要重新导入。请保留原始文件。
- 同一账号下的 GitHub Pages 项目共享 origin，应只在该账号发布可信的网页代码。

## 使用

1. 在手机浏览器打开网站，按需先添加到桌面。
2. 从桌面入口打开，选择导入聊天 JSON（`.chatdb` 是原生 iOS 版使用的格式）。
3. 再依次选择与该聊天匹配的媒体 ZIP；未导入的媒体会显示占位提示。
4. 在聊天菜单中使用查找和日历。

从旧版更新时，如果提示补充分类，请重新选择原聊天 JSON。同一会话的媒体资产、关联和已导入包会保留，不用重复导入 ZIP。可选的 `rawType` 必须是非负安全整数；未保留该字段的记录仍可阅读，但无法完整区分表情和转账。

数据量大时需要足够的设备空间，实际可用浏览器额度由系统决定。建议先导入文字，再逐包导入媒体。

## 开发与部署

无需安装依赖。使用 Node.js 22 或更高版本运行：

```sh
node check.mjs
node check-media.mjs
node check-sw.mjs
node check-public.mjs
```

通过任意静态服务器提供 `dist/`。所有资源采用相对路径，支持根目录或项目子目录。GitHub Actions 只发布 `dist/` 中白名单列出的文件。

在线请求优先读取最新程序；网络不可用时才退回已缓存程序。服务器明确返回 404/410 时不展示旧缓存。离线存储无法远程撤销，删除网站也不会自动删除设备里的聊天。
